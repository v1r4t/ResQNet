# ResQNet

Dynamic Emergency Response Database — a DBMS course project demonstrating database concepts through a dynamic city-wide emergency transportation network.

## Tech Stack

- **Database**: PostgreSQL + PostGIS
- **Backend**: Python + FastAPI + psycopg3
- **Frontend**: React + Vite + Tailwind CSS + MapLibre GL JS + Recharts
- **Routing**: Custom Dijkstra/A* in Python
- **LLM**: Gemini/OpenAI pluggable with mock fallback

## Quick Start

```bash
docker-compose up --build
```

- Frontend: http://localhost:3000
- Backend API: http://localhost:8000
- API Docs: http://localhost:8000/docs
